## About the Project

Cement manufacturing contributes approximately 7%–8% of global anthropogenic $\mathrm{CO}_2$ emissions, primarily from clinker calcination. Replacing clinker with supplementary cementitious materials (SCMs)—such as ground granulated blast-furnace slag, fly ash, limestone filler, and volcanic pozzolan—substantially reduces the embodied carbon of concrete.

However, clinker replacement presents a durability trade-off:
* Cement hydration produces Portlandite ($\mathrm{Ca(OH)}_2$), maintaining pore water $\mathrm{pH} > 12.5$ and passivating embedded steel reinforcement against corrosion.
* High SCM replacement depletes this alkaline reserve through pozzolanic reactions and reduced initial calcium content, accelerating atmospheric $\mathrm{CO}_2$ ingress (carbonation).
* When the carbonation front reaches the depth of steel reinforcement ($d_{\mathrm{cover}}$), depassivation occurs, initiating steel corrosion and cover cracking.

**What this project does:**  
This project develops a constrained lifecycle optimization framework to find concrete mixtures that achieve the lowest possible lifecycle carbon footprint while strictly satisfying structural strength demands and long-term durability constraints. 

Calibrated on an **11-year natural weathering dataset of 45 concrete mixtures** exposed in Chennai, India:
1. **Compressive Strength:** Models 28-day strength using an air-normalized Bolomey formulation that accounts for entrapped air void variability.
2. **Carbonation Kinetics:** Calibrates empirical penetration rates ($d = k \sqrt{t}$) for sheltered (convective diffusion) and unsheltered (monsoon rain attenuation) tropical microclimates.
3. **Constrained Optimization:** Solves multi-variable optimization problems across 18 design scenarios (Grades C30/37 to C40/50, covers 25–35 mm, sheltered vs. unsheltered) using multi-start Sequential Least Squares Programming (SLSQP).
4. **Lifecycle Accounting:** Evaluates cradle-to-gate embodied carbon (Modules A1–A3) and stoichiometric use-phase $\mathrm{CO}_2$ re-absorption (Module B1 uptake) under codified standards (IS 10262, IS 456, EN 206, and EN 16757).

Developed for the course **Modeling of Earth System and Sustainability (MESS)**.

## What the Scripts Do

### 1. `scripts/run_constrained_optimization.py`
The primary analysis engine for the project:
* **Loads & Preprocesses Data:** Reads `data/carbonation_master.csv`, extracting constituent proportions, water-to-binder ratios, fresh air contents, 28-day cylinder strengths, and 11-year carbonation depths.
* **Fits Predictive Models:**
  * Fits the **air-normalized Bolomey strength model**, correcting for batch-to-batch air void variations (1.2%–6.6%) and computing Leave-One-Out Cross-Validation (LOO-CV) prediction errors.
  * Fits multi-variable logarithmic carbonation rate models ($\ln k$) for both sheltered (indoor) and unsheltered (outdoor) conditions as functions of $w/b$ and individual SCM replacement percentages.
* **Discrete Mix Screening:** Screens all 45 physical mixtures in the cohort against target design strengths (with IS 10262 design safety margins) and 50-year cover depth requirements, identifying the lowest-carbon feasible physical mix for each scenario.
* **Continuous Multi-Start Optimization:** Uses SLSQP to solve the nonlinear constrained optimization problem over continuous decision variables (binder content $B$, water-to-binder ratio $w/b$, and individual SCM mass fractions), minimizing net lifecycle carbon subject to strength, durability, and code limits.
* **Sensitivity Sweeps:** Evaluates robustness across eight dimensions, including economic vs. mass allocation of SCM footprints, kinetic uncertainty margins (+15%), compaction air void thresholds, and prescriptive binder minimums (EN 206 vs. IS 456).
* **Generates Outputs:** Saves all summary CSVs into `results/` and produces high-resolution plots (`figures/fig6_pareto_carbon_vs_strength.png` and `figures/fig7_sensitivity_analysis.png`).

### 2. `scripts/verify_all_numbers.py`
An automated verification and quality-assurance test suite:
* **Mathematical Invariants:** Recomputes the analytical closed-form fly ash durability limit, Bolomey strength predictions, slack margins, and break-even compaction air void thresholds.
* **Monotonicity & Bound Verification:** Verifies that inward perturbations from active bounds (higher binder, higher $w/b$, lower SCM replacement) strictly increase net carbon.
* **Shadow Price & Slopes:** Recomputes Kuhn-Tucker cover shadow prices ($\mu_{\mathrm{dur}}^* = 0.41\ \mathrm{kg\ CO_2e/(m^3\cdot mm)}$) and checks the sign of full-objective derivatives across the $[0, 50\%]$ fly ash replacement domain.
* **Scenario Range Validation:** Verifies the complete $4.6\%\text{--}31.2\%$ pre-PCE and $1.1\%\text{--}29.0\%$ post-PCE carbon reduction ranges across all 18 structural scenarios.
* **Statistical Fits:** Validates the clustered OLS regressions for carbonation time exponents ($n = 0.509$ sheltered, $n = 0.452$ unsheltered).

### 3. `paper/compile.sh`
The manuscript build script:
* Executes `pdflatex`, `bibtex`, and two follow-up `pdflatex` compilation passes to resolve cross-references, equations, and citations.
* Checks the page count against the strict 10-to-11-page camera-ready layout budget and updates `paper/final_main_ieee.pdf`.

## Quickstart & Reproducibility

### Setup Environment
```bash
git clone https://github.com/abhitejj/low-carbon-concrete-optimization.git
cd low-carbon-concrete-optimization

pip install -r requirements.txt
```

### Run Optimization
```bash
python scripts/run_constrained_optimization.py
```

### Run Verification Checks
```bash
python scripts/verify_all_numbers.py
```

### Build the Manuscript PDF
```bash
cd paper
chmod +x compile.sh
./compile.sh
```
